Predicting the NBA MVP with Machine Learning

A Comparative Study of Naive Bayes and Logistic Regression

Motivation

The NBA MVP is voted by sportswriters and broadcasters, making the decision partly subjective. This project asks whether machine learning can predict the MVP using only objective season statistics.

Problem Statement

Given the top 3 MVP finalists in a season, can we correctly identify the winner using 10 per-game statistics? We compare a generative model (Naive Bayes) with a discriminative model (Logistic Regression).

Dataset

  • Source: Kaggle / Basketball-Reference
  • Seasons: 2000-01 to 2019-20
  • Rows: 60 (20 × top 3 finalists)
  • Train: 48 rows (2000-2016)
  • Test: 12 rows (2017-2020)

Features

  • Games played, Minutes per game
  • FG%, 3P%, FT%
  • Rebounds, Assists, Steals, Blocks per game
  • Points per game

Naive Bayes

Probabilistic generative classifier. Assumes features are independent and follow a Gaussian distribution per class. Fast and simple, but the independence assumption is often violated in basketball stats.

Logistic Regression

Discriminative linear classifier that learns P(MVP | features) directly. Features are standardized. Outputs probabilities used for both pure and seasonal prediction.

Pure MVP Mode

Each finalist is independently classified as MVP or non-MVP using a probability threshold of 0.5. Standard binary classification accuracy.

Seasonal MVP Mode

One MVP must be chosen per season. The finalist with the highest predicted probability within each season is selected. More realistic and stricter.

Results

Model Train (pure) Test (pure) Test (seasonal)
Naive Bayes 60.4% 41.7% 50.0%
Logistic Regression 79.2% 50.0% 66.7%

Key insight: Logistic Regression wins on the realistic seasonal task. Naive Bayes underperforms because basketball features are correlated, violating its independence assumption.

Discussion

Logistic Regression outperforms Naive Bayes, especially in seasonal mode. Top predictive features are assists, free-throw %, points, blocks, and rebounds. The small dataset and missing voter-narrative factors limit accuracy.
